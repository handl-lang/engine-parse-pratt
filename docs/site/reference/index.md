# Reference

## Public API

| item | what it is |
|---|---|
| `GrammarRow` input | prefix/infix descriptors keyed by token and position |
| `Ast` output | arena of nodes; the **root node is the last node** of the arena |
| `ParserEngine` impl | the `engine-parse` contract |

## Crate

| crate | role |
|---|---|
| `hnl-engine-parse-pratt` | engine implementation |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
